Curriculum for the **Founding CPO / Head of Product** role — the first product
hire at a pre-seed → Series-B startup. Level 35 in the Startup Leadership
family.

> **Status:** curriculum plan authored (7 modules / 112 h + 3 projects / 160 h
> = 272 h). mod-001 (Customer Discovery → PMF) is authored; mod-002 → mod-007
> and the three capstone projects are produced by the autonomous
> research → author pipeline (oldest-gap-first). Run `aicg org research` and
> `aicg org daily` to drive the fill-in loop.
